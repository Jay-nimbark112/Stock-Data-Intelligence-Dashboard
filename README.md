# Stockly: AI-Powered Stock Dashboard

### 🚀 Features
- **Real-time Data:** Fetches live NSE data via `yfinance`.
- **ML Predictions:** Uses Scikit-Learn Linear Regression to forecast trends.
- **Technical Indicators:** Moving Averages, Volatility, and Market Correlation.
- **Modern UI:** Cyber-Emerald Dark Theme built with Vite & Recharts.

### 🛠️ Tech Stack
- **Frontend:** React + Vite + Recharts + Axios
- **Backend:** Flask + Pandas + Scikit-Learn
- **DevOps:** Dockerized Backend
